## 1. 왜 지금인가

2026년 7월 17일, AWS 빌링 시스템이 S3 용량을 GB 대신 byte로 계산하면서 **2^30배 뻥튀기된 예상 청구서**를 뿌렸다. 월 0.19달러 쓰던 계정에 25억 달러 추정치가 찍혔고, 영국의 한 자선단체는 58억 파운드를 통보받았다. 더 중요한 건 사후 분석이다 — AWS 내부 알람은 이상을 감지했지만 청구서 생성을 멈추거나 엔지니어를 호출하지 못했고, 고객 에스컬레이션으로 4.5시간 뒤에야 인지했다. ([InfoQ 정리](https://www.infoq.com/news/2026/07/aws-billing-estimates-incident/), ["Your Billing Alarm Is Watching a Fiction"](https://paddo.dev/blog/billing-alarm-fiction/))

이 사건이 드러낸 구조적 문제: **Cost Explorer는 최대 24시간 지연, Budgets 알림은 하루 최대 3회**. 즉 우리가 믿고 있던 비용 알람은 실시간이 아니다. 실제로 2026년 개발자 불만 데이터 분석에서도 클라우드 과금 사고가 AI 신뢰성과 함께 1위 페인포인트로 잡혔다 ([Dev|Journal, 2026-04](https://earezki.com/ai-news/2026-04-21-what-1000-developer-posts-told-me-about-the-biggest-pain-points-right-now/)). 잘못된 루프 하나로 8일 만에 3.4만 달러가 나간 사례가 대표적이다.

## 2. 어떤 문제를 푸는가

빌링 API를 폴링하는 툴은 이미 많다. 그런데 빌링 API 자체가 늦거나 틀리면 전부 무용지물이다. 그래서 **과금 데이터를 아예 보지 않는다.** 대신 CloudWatch 사용량 메트릭(초 단위로 정확하고 지연 5분 이내)에 단가표를 곱해 *시간당 번레이트(원/시)* 를 자체 추정한다. NAT Gateway 바이트, EC2 인스턴스-시간, S3 요청 수, Lambda 호출, 데이터 전송량 — 사고의 90%는 이 다섯 개에서 난다.

## 3. MVP 범위 (하루치)

- 읽기 전용 IAM Role + `GetMetricData` 배치 호출 (5분 주기)
- 리전별 단가표는 JSON 하드코딩 (Pricing API는 느리고 복잡하다)
- SQLite 시계열 적재 → 최근 1시간 번레이트 계산
- 이상 탐지: 지난 7일 **같은 요일·같은 시간대 중앙값 대비 3배 초과** (단순 평균은 배치 잡에 오탐난다)
- Discord/Slack Webhook 경보 + 일 1회 요약 텍스트
- 프론트엔드 없음. 대시보드는 경보 메시지가 대신한다.

## 4. 기술 스택

Python 3.12 + boto3, SQLite(WAL), APScheduler, Docker 단일 컨테이너. VPS 한 대 또는 Fly.io 무료 티어. 상태가 SQLite 파일 하나라 백업이 `cp`다.

## 5. 핵심 코드

```python
# 돈이 새는 곳만 골라서 한 번에 긁는다 (GetMetricData는 500개까지 배치)
PRICE = {  # USD, ap-northeast-2 기준
    "nat_bytes":   0.059 / (1024**3),   # NAT 처리 GB당
    "s3_get":      0.0004 / 1000,       # GET 1000건당
    "lambda_inv":  0.20 / 1_000_000,
}

def burn_rate(rows: dict[str, float], window_sec: int) -> float:
    """window 동안의 사용량 -> 시간당 예상 지출(USD/h)"""
    cost = sum(PRICE[k] * v for k, v in rows.items() if k in PRICE)
    return cost * 3600 / window_sec

# 기준선: 같은 요일·같은 시각의 과거 값 (배치 잡 오탐 방지)
SQL = """
SELECT rate FROM burn
 WHERE strftime('%w%H', ts) = strftime('%w%H', ?)
   AND ts < datetime(?, '-1 hour')
 ORDER BY ts DESC LIMIT 7
"""

def is_anomaly(now_rate, baseline: list[float], k=3.0) -> bool:
    if len(baseline) < 3:
        return False              # 학습 기간엔 침묵한다
    med = sorted(baseline)[len(baseline)//2]
    return now_rate > max(med * k, 0.05)   # 절대 하한으로 푼돈 오탐 차단
```
