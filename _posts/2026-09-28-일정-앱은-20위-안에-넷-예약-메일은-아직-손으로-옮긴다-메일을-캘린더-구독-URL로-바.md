## 순위에서 읽은 것

네이버 캘린더, AnySchedule, LockDay, minical까지 일정 앱이 20위 안에 넷이다. Gmail과 네이버 메일도 함께 올라 있다. AnySchedule은 "문장 한 줄·사진 한 장이면 AI가 일정을 대신 등록"한다는 점을 앞에 내세운다. 일정 입력이 귀찮다는 수요는 이미 확인된 셈이다. 그런데 일정이 처음 들어오는 곳인 메일함과 캘린더 사이는 아직도 사람이 복사해서 옮긴다.

## 만들 것

IMAP으로 메일함을 읽는 서버다. 항공권·공연·병원·식당 예약 확인 메일에서 제목, 시각, 장소를 뽑아 구독용 ICS URL 하나로 내보낸다. 캘린더 앱은 바꿀 필요 없이 URL만 구독하면 되니 어떤 앱을 쓰든 붙는다. 예약 메일이 여러 메일함에 흩어져 있는 나와 가족을 위한 도구다.

## 8시간 범위

- Gmail, 네이버 메일 두 계정을 앱 비밀번호로 10분마다 폴링
- 허용한 발신자의 메일만 LLM API에 넣어 제목·시작 시각·장소를 JSON으로 추출
- Message-ID를 키로 SQLite에 저장해 같은 메일은 한 번만 처리
- 토큰이 붙은 비공개 URL로 ICS 제공, 잘못 뽑힌 일정은 웹 목록에서 삭제

## 스택과 시간 배분

Python, imaplib, FastAPI, SQLite, cron, LLM API

| 시간 | 할 일 |
| --- | --- |
| 0~2h | IMAP 접속, 발신자 필터, 본문 텍스트 추출, SQLite 스키마 |
| 2~5h | 추출 프롬프트와 JSON 검증, 실제 예약 메일 20통으로 정확도 확인 |
| 5~8h | ICS 엔드포인트, 삭제용 웹 목록, cron 등록과 캘린더 구독 테스트 |
