## 순위에서 읽은 것

20위 안에 언어 학습 앱이 일곱 개다. 듀오링고, 말해보카, 랭플릭스, YayTalk, HelloTalk, 헤이링, Praktika가 있고, 단어장 앱인 클래스카드도 18위에 있다. 단어를 외우려는 사람은 확실히 많다. 그런데 단어장은 앱마다 따로 있다. 랭플릭스에서 건진 숙어와 헤이링 통화에서 막힌 표현을 한곳에 모아 복습할 방법이 없다.

## 만들 것

어느 앱에서 만난 단어든 텔레그램 봇에 "단어 = 뜻" 형식으로 보내면 저장해 둔다. 매일 아침에는 그날 복습할 카드만 골라서 보내 준다. 카드마다 있는 "알았다/몰랐다" 버튼을 누르면 라이트너 상자 방식으로 다음 복습일이 정해진다. 여러 앱을 오가며 공부하는 사람이 혼자 쓰는 복습 큐다.

## 8시간 범위

- 텔레그램 웹훅으로 단어 등록. 한 줄에 하나씩 여러 개를 한 번에 붙여 넣어도 된다
- 매일 정해진 시각에 복습할 카드를 인라인 버튼과 함께 발송
- 버튼을 누르면 콜백으로 카드의 상자를 옮기고 다음 복습일을 갱신
- /stats 명령으로 상자별 카드 수와 오늘 남은 복습 수 확인

## 스택과 시간 배분

Python, FastAPI, SQLite, APScheduler, Telegram Bot API

| 시간 | 할 일 |
| --- | --- |
| 0~2h | 봇 등록, 웹훅 수신, 카드 테이블 설계, 등록 메시지 파싱 |
| 2~5h | 복습 스케줄러, 인라인 버튼 발송, 콜백 처리 |
| 5~8h | /stats 구현, 사용자별 발송 시각 설정, 배포, 재시작해도 두 번 발송되지 않게 처리 |

다음 복습일 계산은 아래 함수 하나로 끝난다.

```python
from datetime import timedelta

INTERVALS = [1, 2, 4, 8, 16, 32]  # 상자별 복습 간격(일)

def review(card, knew, today):
    card.box = min(card.box + 1, len(INTERVALS) - 1) if knew else 0
    card.due = today + timedelta(days=INTERVALS[card.box])
    return card
```
