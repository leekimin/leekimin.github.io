## 순위에서 읽은 것

모두닥, 강남언니, 바비톡, 여신티켓 네 개가 20위 안에 있다. 시술 가격을 비교하고 싶어 하는 사람이 많다는 뜻이다. 그런데 이 앱들이 보여 주는 값은 병원이 플랫폼에 낸 가격표나 할인가다. 같은 목록 12위인 건강e음을 운영하는 건강보험심사평가원도 비급여 진료비를 공개하지만, 두 값을 나란히 놓고 보여 주는 도구는 없다.

## 만들 것

병원 이름, 항목, 견적 금액을 넣으면 세 가지를 돌려주는 API와 한 페이지짜리 조회 화면이다. 그 병원이 심평원에 신고한 비급여 가격, 같은 시군구 병원들의 최저·중앙·최고값, 그리고 견적이 그중 어디쯤인지다. 상담에서 받은 견적이 신고가보다 비싼지, 동네에서 어느 위치인지 확인하고 싶은 사람을 위한 것이다.

## 8시간 범위

- 공공데이터포털의 심평원 비급여 진료비 API에서 관심 항목 몇 개(임플란트, 시력교정술 등)만 수집해 적재
- 병원명 부분 일치 검색, 항목명과 코드 매핑 테이블
- 견적 대조 API: 신고가와의 차이, 시군구 안에서의 백분위
- 주 1회 다시 수집하는 스케줄러, 가격이 바뀐 병원은 변경 로그에 남김

## 스택과 시간 배분

Python, FastAPI, SQLite, httpx, APScheduler, Jinja2 템플릿 한 장

| 시간 | 할 일 |
| --- | --- |
| 0~2h | API 키 발급, 응답 구조 확인, 수집기와 테이블 작성, 첫 적재 |
| 2~5h | 병원 검색, 항목 매핑, 견적 대조와 백분위 계산 API |
| 5~8h | 조회 화면, 재수집 스케줄러와 변경 로그, 컨테이너로 배포 |
