## 순위에서 읽은 것

현대카드, 신한 SOL페이, 모니모까지 카드 앱 셋이 20위 안에 있다. 토스는 소개 문구에 "카드 실적도 모아볼 수 있어요"라고 적었다. 그만큼 실적을 확인하려는 수요는 이미 검증됐다. 비어 있는 곳은 다른 데 있다. 카드마다 실적 기준과 제외 업종이 다른데, 이를 내 규칙대로 계산해서 다음 결제를 어느 카드로 해야 하는지까지 알려 주는 도구는 목록에 없다.

## 만들 것

카드 승인 문자를 웹훅으로 받아 카드별로 이번 달 실적을 쌓는다. 그리고 실적 구간까지 남은 금액을 텔레그램으로 알려 주는 봇을 만든다. 카드 두세 장을 실적 구간에 맞춰 나눠 쓰는 사람이 자기 서버에 띄워 쓰는 용도다.

## 8시간 범위

- 승인·취소 문자를 웹훅으로 받고, 정규식으로 카드·금액·가맹점을 파싱한다
- 카드별 실적 기준 금액과 제외 가맹점 키워드는 YAML 파일 하나로 정의한다
- 매일 밤 9시에 "A카드 12만 원 남음, B카드 달성" 같은 요약을 보낸다
- 월말 5일 전부터는 실적을 못 채운 카드만 골라 따로 알린다

## 스택과 시간 배분

FastAPI, SQLite, APScheduler, Telegram Bot API, Docker 컨테이너 하나

| 시간 | 할 일 |
| --- | --- |
| 0~2h | 웹훅 엔드포인트 작성, 실제로 받은 문자 샘플 10건으로 승인·취소 파서 테스트 |
| 2~5h | 거래 테이블과 YAML 규칙 로딩, 제외 업종 판정, 카드별 잔여액 계산 |
| 5~8h | 일일 요약과 월말 경고 스케줄링, Docker 배포, 휴대폰 문자 전달 자동화 연결 |

취소 건은 음수 금액으로 저장한다. 이렇게 하면 잔여액 계산이 쿼리 하나로 끝난다.

```python
def remaining(conn, card, target, month):
    spent = conn.execute(
        "SELECT COALESCE(SUM(amount), 0) FROM tx "
        "WHERE card = ? AND month = ? AND excluded = 0",
        (card, month),
    ).fetchone()[0]
    return max(target - spent, 0)
```
