## 목록에서 읽은 것

오늘 무료 순위 20개 중 8개가 구인·구직 앱이다. 1위 고용24에 사람인, 알바몬, 잡코리아, 리멤버, 쿠펀치, 벼룩시장, 알바천국이 이어진다. 앱 하나가 튄 게 아니라 카테고리가 통째로 올라왔다. 국방 관련 앱 두 개가 2위와 13위에 있는 것도 눈에 띄는데, 이쪽은 특정 날짜에만 반복되는 패턴일 가능성이 크다.

## 고른 앱

고용24(한국고용정보원)를 축으로 잡고 나머지 일곱 개를 같이 묶는다. 고용24는 실업급여와 국민취업지원제도 신청 창구라 순위가 정책 일정에 바로 반응한다. 민간 구직 앱과 같이 움직이는지, 고용24만 따로 튀는지가 이 지표에서 볼 것의 전부다.

## 8시간 계획

- Apple RSS 피드(rss.applemarketingtools.com)로 KR 무료 top 100을 받는다. 키가 필요 없다
- SQLite에 (날짜, 앱ID, 순위)로 쌓고 앱ID로 구직 앱 여덟 개를 태깅한다
- 순위를 101-rank 점수로 바꿔 합산하고, 하루 한 값짜리 지수로 만든다
- CLI 세 개: today, trend, spike. 급등은 7일 이동평균 대비 편차로 잡는다

## 하루치 작업 계획

| 시간 | 할 일 |
| --- | --- |
| 0~2h | 피드 응답 구조 확인, 수집 스크립트와 SQLite 테이블 작성 |
| 2~5h | 앱ID 태깅, 지수와 이동평균 계산, 스냅샷 여러 개로 검증 |
| 5~8h | CLI 서브커맨드 세 개, GitHub Actions로 하루 1회 실행, README |
