## 순위에서 읽은 것
유니클로, 무신사, 에이블리, 29CM, ZARA, 스파오까지 옷을 파는 앱이 20위 안에 여섯 개 있다. 쿠팡은 앱 설명에서 '로켓배송상품 30일 무료반품'을 따로 내세운다. 옷은 입어 봐야 맞는지 알기 때문에 반품도 쇼핑의 일부다. 그런데 반품 기한은 앱마다 다르다. 여러 앱에서 산 주문의 기한을 한곳에서 챙겨 주는 앱은 이 목록에 없다.

## 만들 것
여러 쇼핑몰에서 옷을 사는 사람에게 반품 기한을 알려 주는 서버다. 주문 확인 메일을 전용 주소로 전달하면 서버가 쇼핑몰, 상품명, 주문일을 뽑아 저장한다. 그리고 마감 3일 전부터 매일 아침 텔레그램으로 알린다. 화면은 따로 없고 메일 웹훅과 봇만으로 동작한다.

## 8시간 범위
- 메일 수신 웹훅으로 주문 메일을 받고, 쇼핑몰별 정규식 3~4개로 필요한 값 추출
- 기본 기한은 7일로 두고, 쇼핑몰별 기한은 설정 파일에서 바꾸기
- 봇 명령 /받음, /반품함 으로 받은 날짜와 반품 여부 기록
- 매일 08시 스케줄러가 마감 3일 이내 주문을 모아 한 번에 발송

## 스택과 시간 배분
Python, FastAPI, SQLite, Mailgun 수신 라우트, cron, Telegram Bot API

| 시간 | 할 일 |
| --- | --- |
| 0~2h | 웹훅 엔드포인트, 테이블 설계, 메일 원문 저장 |
| 2~5h | 쇼핑몰별 파서 작성. 파싱에 실패하면 원문 일부를 붙여 봇이 직접 입력을 요청 |
| 5~8h | 봇 명령, 알림 스케줄러, 실제 주문 메일로 처음부터 끝까지 테스트 |

기한은 받은 날짜를 기준으로 하고, 받은 날짜를 모르면 주문일로 계산한다.

```sql
SELECT mall, item,
       date(COALESCE(received_at, ordered_at), '+' || return_days || ' days') AS deadline
FROM orders
WHERE returned = 0
  AND date(COALESCE(received_at, ordered_at), '+' || return_days || ' days')
      BETWEEN date('now', 'localtime') AND date('now', 'localtime', '+3 days');
```
