## 순위에서 읽은 것

淘宝와 Temu가 한국 쇼핑 무료 순위 20위 안에 함께 올라 있다. 해외 직구 수요는 이미 검증됐다는 뜻이다. 그런데 주문 앱의 배송 화면은 대개 '배송 중'에서 멈춘 채, 물건이 입항했는지 통관 보류에 걸렸는지 말해 주지 않는다. 같은 목록의 쿠팡이 '내일 도착'을 앞세우는 것과 비교하면 이 부분이 비어 있다.

## 만들 것

B/L 번호를 등록하면 관세청 UNI-PASS 화물통관 진행정보 조회 API를 주기적으로 호출하고, 단계가 바뀔 때만 텔레그램으로 알려 주는 서버다. 직구를 여러 건 동시에 넣는 사람이나 가족 주문까지 대신 챙기는 사람이 쓰도록 만든다. 그러면 여러 앱을 돌아다니며 새로고침할 필요가 없다.

## 8시간 범위

- 텔레그램 봇 명령 /add, /list, /del로 B/L 번호와 입항 연도를 등록·조회·삭제
- 30분 주기 스케줄러가 API를 호출하고, 직전 상태와 다를 때만 알림 전송
- 반출 신고처럼 통관이 끝난 단계가 오면 해당 건 추적 자동 종료
- 건별 상태 이력을 시간순으로 보여 주는 단순한 웹 화면 한 장

## 스택과 시간 배분

Python, FastAPI, APScheduler, SQLite, httpx, python-telegram-bot

| 시간 | 할 일 |
| --- | --- |
| 0~2h | 미리 발급받은 UNI-PASS 인증키로 API 호출, 응답 XML 파싱, 진행 단계 이름 정규화 |
| 2~5h | 봇 명령 처리, SQLite 저장, 스케줄러와 상태 변경 감지 및 알림 |
| 5~8h | 이력 웹 화면, API 실패 시 재시도, 서버 배포 후 실제 주문 1건으로 검증 |

인증키 발급에는 시간이 걸릴 수 있으니 시작 전날 신청해 둔다. 8시간에는 인증키를 기다리는 시간을 넣지 않았다.
