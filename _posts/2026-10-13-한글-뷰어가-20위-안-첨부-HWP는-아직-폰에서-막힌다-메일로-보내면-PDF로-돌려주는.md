## 순위에서 읽은 것

10위 '한글 뷰어 - HWPX, HWP 뷰어, 편집'이 Google Chrome, 네이버 MYBOX와 함께 20위 안에 있다. 폰에서 HWP 파일을 열려고 앱을 따로 깔 만큼 수요가 크다는 뜻이다. 18위 VestMail까지 함께 보면, 공문과 안내문은 여전히 메일 첨부로 온다. 그런데 받는 사람의 기기에서 그 파일이 열리는지는 보내는 쪽이 신경 쓰지 않는다.

## 만들 것

HWP·HWPX 파일이 첨부된 메일을 전용 주소로 전달하면, PDF로 바꿔 답장해 주는 서버다. 앱을 마음대로 설치할 수 없는 회사 폰 사용자, 가정통신문을 단톡방에 올려야 하는 학부모, 팀 공용 메일함이 대상이다. 앱을 설치할 필요 없이 메일 전달 한 번이면 된다.

## 8시간 범위

- 인바운드 메일 웹훅으로 메일을 받아 .hwp/.hwpx 첨부만 골라 저장
- LibreOffice 헤드리스와 H2Orestart 확장으로 PDF 변환, 실패하면 hwp5txt로 텍스트만 추출
- PDF를 첨부하고 문서 앞부분 텍스트를 본문에 넣어 답장
- 발신자 허용 목록, 첨부 10MB 제한, 처리 이력을 보는 간단한 웹 화면

## 스택과 시간 배분

Python, FastAPI, Mailgun 인바운드 라우트·발송 API, LibreOffice + H2Orestart, pyhwp, SQLite, Docker

| 시간 | 할 일 |
| --- | --- |
| 0~2h | Docker 이미지에 LibreOffice·H2Orestart·pyhwp 설치, 샘플 HWP·HWPX로 변환 확인 |
| 2~5h | 웹훅 엔드포인트, Mailgun 서명 검증, 첨부 추출, 변환 타임아웃 처리 |
| 5~8h | 답장 발송, 허용 목록과 크기 제한, 이력 화면, 깨진 파일·암호 걸린 파일 오류 회신 |

```python
import subprocess
from pathlib import Path

def to_pdf(src: Path, outdir: Path) -> Path:
    subprocess.run(["soffice", "--headless", "--convert-to", "pdf",
                    "--outdir", str(outdir), str(src)],
                   check=True, timeout=120)
    return outdir / f"{src.stem}.pdf"
```
