## 순위에서 읽은 것

유틸리티 20위 안에 Proton VPN(6위), NordVPN(8위), 무료 VPN(19위)까지 VPN 앱이 셋 있습니다. 이름에 VPN을 넣은 Brave(11위)와 Unicorn HTTPS(18위)까지 더하면 '내 트래픽을 숨기고 싶다'는 앱이 다섯 개입니다. 그런데 켜 놓은 VPN이 실제로 IP와 DNS 질의를 감추는지 확인해 주는 도구는 목록에 하나도 없습니다. 특히 무료 VPN은 믿고 쓰기가 더 어렵습니다.

## 만들 것

브라우저로 접속하면 서버가 본 공인 IP, 내 DNS 질의를 실제로 처리한 리졸버 IP, WebRTC로 드러나는 로컬 주소를 한 화면에 보여 주는 검사 서버입니다. VPN을 여러 개 번갈아 쓰는 사람, 그리고 가족이나 팀원에게 "이 링크 열어서 캡처해 줘" 하고 보낼 사람을 위한 것입니다. 원리는 간단합니다. 매 요청마다 랜덤 서브도메인을 만들고, 그 도메인의 권한 DNS 서버를 직접 띄워서 누가 물어보러 왔는지 기록합니다.

## 8시간 범위

- 서브도메인 NS 위임과 권한 DNS 서버. 토큰별로 질의해 온 리졸버 IP를 기록
- HTTP 엔드포인트. 토큰을 발급하고 결과를 JSON으로 반환
- 결과 화면 한 장. 리졸버 IP의 ASN과 국가가 VPN 출구와 다르면 빨간색으로 표시
- `curl`로도 쓸 수 있는 CLI 모드. 서버 사이드 VPN 점검용

## 스택과 시간 배분

Go, miekg/dns, net/http, MaxMind GeoLite2 ASN DB, 단일 VPS

| 시간 | 할 일 |
| --- | --- |
| 0~2h | 도메인 NS 위임, DNS 핸들러, 토큰 저장소 |
| 2~5h | 토큰 발급 API, 프론트에서 서브도메인 5개 병렬 조회, ASN 조회 붙이기 |
| 5~8h | 결과 화면과 WebRTC 검사, curl 출력, 토큰 TTL 정리, 배포 |

```go
dns.HandleFunc("leak.example.com.", func(w dns.ResponseWriter, r *dns.Msg) {
	q := r.Question[0].Name // <token>.leak.example.com.
	token := strings.SplitN(q, ".", 2)[0]
	resolver, _, _ := net.SplitHostPort(w.RemoteAddr().String())
	seen.Store(token, resolver)
	m := new(dns.Msg).SetReply(r)
	rr, _ := dns.NewRR(q + " 60 IN A 203.0.113.10")
	m.Answer = append(m.Answer, rr)
	w.WriteMsg(m)
})
```
