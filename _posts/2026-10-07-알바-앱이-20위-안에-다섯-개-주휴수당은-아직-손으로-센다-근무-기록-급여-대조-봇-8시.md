## 순위에서 읽은 것
알바몬, 알바천국, 고용24가 20위 안에 있으니 일자리를 구하려는 수요는 검증됐다. 쿠펀치는 출퇴근 체크를, 하우머치는 급여 계산을 맡아 일한 뒤의 관리까지 앱이 필요하다는 것을 보여 준다. 그런데 어느 앱도 여러 근무지 기록을 한데 모아 통장에 실제로 들어온 돈과 맞춰 보지는 않는다.

## 만들 것
텔레그램 봇에 /in, /out만 보내면 근무 시간이 쌓이고, 주 단위로 주휴수당을 포함한 예상 급여를 계산하는 서버다. 급여일에 실제 입금액을 입력하면 예상 금액과의 차액을 알려 준다. 대상은 두세 곳에서 동시에 일하는 아르바이트생과 그 가족이다.

## 8시간 범위
- 텔레그램 봇 명령 /in, /out, /job(근무지·시급 등록), /paid(입금액 입력)
- 주 15시간 이상이면 주휴수당을 계산하고, 최대 40시간 기준으로 비례 산정
- 매주 월요일 아침에 지난주 근무지별 시간과 예상 금액 요약 발송
- 입금액이 예상보다 적으면 차액과 근거가 되는 근무 기록 목록 발송

## 스택과 시간 배분
Python, FastAPI(웹훅 수신), SQLite, APScheduler, Telegram Bot API

| 시간 | 할 일 |
| --- | --- |
| 0~2h | 스키마(근무지, 근무 기록, 입금), 웹훅 수신과 명령 파싱 |
| 2~5h | 주별 집계, 주휴수당 계산, 퇴근 누락 시 경고 |
| 5~8h | 월요일 요약 스케줄러, 입금 대조 알림, 배포 |

```python
def weekly_allowance(week_minutes: int, wage: int) -> int:
    hours = week_minutes / 60
    if hours < 15:
        return 0
    return round(min(hours, 40) / 40 * 8 * wage)
```
