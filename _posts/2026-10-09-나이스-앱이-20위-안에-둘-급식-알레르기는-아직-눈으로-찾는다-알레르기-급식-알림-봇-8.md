## 순위에서 읽은 것

20위 안에 나이스플러스(NEIS+)와 나이스학부모서비스가 함께 올라 있고, 아이사랑 모바일도 있다. 학부모가 학교 생활 정보를 휴대폰으로 확인하려는 수요는 이 순위로 확인된다. 그런데 급식표를 열어 메뉴 옆의 알레르기 번호를 하나씩 맞춰 보는 일은 아직 부모가 직접 한다.

## 만들 것

나이스 교육정보 개방 포털의 급식 API를 매일 읽고, 아이가 피해야 하는 알레르기 번호가 들어간 메뉴만 골라 전날 저녁 텔레그램이나 슬랙으로 보내는 봇이다. 자녀가 여럿이고 학교가 서로 달라도 자녀마다 설정 한 줄만 추가하면 된다. 알레르기가 있는 아이를 키우는 부모와 보건교사가 쓰는 도구다.

## 8시간 범위

- 학교 이름으로 교육청·학교 코드를 찾는 CLI, 자녀별 설정(학교, 피할 번호) 저장
- 매일 18시에 다음 날 급식을 수집하고 메뉴별 알레르기 번호를 파싱
- 걸리는 메뉴만 웹훅으로 보내고, 없으면 "해당 없음" 한 줄만 보냄
- 이번 주 급식에서 걸리는 메뉴를 강조한 정적 HTML 한 장

## 스택과 시간 배분

Python, httpx, SQLite, cron, 텔레그램 Bot API

| 시간 | 할 일 |
| --- | --- |
| 0~2h | API 키 발급, 학교 검색 CLI, 설정 스키마와 SQLite 테이블 |
| 2~5h | 급식 수집, 알레르기 파싱, 휴일·방학 빈 응답 처리, 테스트 |
| 5~8h | cron 등록, 웹훅 발송, 주간 HTML 생성, 실패 시 재시도 |

급식 API의 `DDISH_NM`은 메뉴를 `<br/>`로 구분하고, 메뉴 끝에 `(1.2.5.6.)` 형식으로 알레르기 번호를 붙인다. 핵심 로직은 아래 함수 하나다.

```python
import re

def flag(ddish_nm: str, avoid: set[int]) -> list[str]:
    hits = []
    for dish in ddish_nm.split("<br/>"):
        m = re.search(r"\(([\d.]+)\)\s*$", dish.strip())
        codes = {int(c) for c in m.group(1).split(".") if c} if m else set()
        if codes & avoid:
            hits.append(dish.strip())
    return hits
```
